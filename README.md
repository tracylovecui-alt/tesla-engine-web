# DriveTone

原创的浏览器虚拟引擎演示，针对车内横屏和手机布局设计。音频由 Web Audio 播放开源赛车循环采样，并叠加本地合成，不使用 EngineV1 的代码、图片或声音素材；没有车辆接口、后端、账号或订阅。

## 使用

1. 在停车时打开 HTTPS 网址。
2. 默认演示模式，可点击启动、拖动车速或运行自动巡航演示。
3. GPS 跟随：选择该模式，点击启动，允许位置访问。
4. 用车辆的媒体音量控制最终响度。页面需保持前台，后台切回时点击恢复声音。

GPS 速度优先采用浏览器提供的 `coords.speed`，没有时通过坐标距离差分估算；过滤低精度和异常跳变，平滑速度。转速、挡位、油门均为模拟值。信号过期时标记延迟，丢失时显示末次车速且声音回落到怠速。

配置存于 localStorage，位置只在内存里处理。无分析统计、外部脚本或坐标上传。本版本 V8 / V10 使用开源赛车循环采样，其原始实车录音来源未确认；Future Drive 为合成音色。实际 Tesla 浏览器的行驶限制、定位速度、系统后台节流和扬声器表现须在对应车辆确认；不能通过本网站绕过车机限制。

## 声音版本 1.2

V8 / V10 以 Speed Dreams 循环采样为主，加入循环接缝平滑、音量归一化、负载滤波和等功率混合；加速与收油是同一录音的两种处理，并非独立的多转速录音库。首次启动下载约 575 KB WAV。来源及许可见 [audio/NOTICE.md](audio/NOTICE.md)，保留上游 GPL / Free Art License 声明。网页代码仍独立提供 MIT 许可。

## 原有合成层 1.1

V8 / V10 使用双缸列 720° 点火脉冲波形，叠加曲轴低频与进气噪声；排气饱和、固定共鸣和随负载变化的滤波形成不同转速音色。换挡包含短暂断火与低频冲击。仍为合成声音，不是车辆录音。

## 本地预览

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 http://127.0.0.1:8080 。演示可直接运行。公网 GPS 需要 HTTPS。
